## K1NG-Driver

a driver for K1NG PRO (4K) mouse from redragon

### Downloading
u can download the driver from [Release's](https://github.com/cfels/K1NG-Driver/releases)

### Compiling

```
nix-shell --run "make clean && make"
sudo ./k1ng_driver
```
